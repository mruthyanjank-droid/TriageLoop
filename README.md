# TriageLoop — Adaptive Emergency Triage Queue System

## Project Overview
TriageLoop is a hackathon prototype designed to process patient events, track patient and resource states, calculate simplified NEWS2-inspired scores, and generate advisory alerts to support emergency department triage workflows.

## Team Responsibilities
- **Person A — Engine Lead:** Event processing, patient state reconstruction, scoring, alerts, and automated tests.
- **Person B:** Project component and tasks assigned by the team.
- **Person C:** Dashboard development and integration.

## Technology Stack
- Python
- pytest
- Git and GitHub

## Core Features
- Duplicate event detection
- Timestamp-ordered event replay
- Patient and resource state tracking
- NEWS2-inspired simplified scoring
- Resource-delay and reassessment alerts
- Temporary alert dismissal

## Disclaimer
This is an educational hackathon prototype, not a clinically validated medical system. Scores and alerts are advisory and do not replace professional clinical judgment.
